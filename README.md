# spa-massage-page

Trang giới thiệu spa massage tại TP. Hồ Chí Minh. Thông tin của spa được cập nhật trong `business.js`.

Để xem trang trên máy, chạy lệnh sau trong thư mục chứa `index.html`.

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Mở [bản xem trước](http://127.0.0.1:8765/).
